# Source and example provenance

The Case2Skill source, task simulator and demonstration cases in this release were independently authored for this project. No private classroom records, industrial datasets or jointly developed project code are included.

The recorded-revision example contains selected model-generated instructions and actions from actual development runs over those synthetic cases. Its README explains the removed metadata and the distinction between replay consistency and third-party authenticity. These example files are distributed with the project under the MIT license. A candidate status is not an endorsement of its operational advice.

There are no third-party runtime dependencies. Development dependencies and their exact versions are in package-lock.json; their own licenses continue to apply. Node.js, Codex and GitHub Actions are separate projects, not bundled with or endorsed by Case2Skill. Codex account usage and model terms apply independently.

Case2Skill writes a small subset of the open Agent Skills format. It does not claim to implement every legal YAML construct or every host's skill-loading behavior. No code was copied from the Agent Skills specification or from other skill-extraction projects.

Materials you import retain their original rights and confidentiality obligations. A generated skill or the MIT license on this tool does not grant permission to redistribute your source material.
