# Changelog

## 0.1.0 — 2026-10-12

Initial source release, prepared locally for GitHub.

- Source-linked skill extraction, deterministic compilation, inspection and review-only export.
- Recorded model replay with a self-contained, offline interactive page.
- `init` for a user's own case and `refine` for updates based on additional evidence.
- A narrowly scoped, replay-checked feedback workflow and parent/child version comparison.
- Seven local report-service scenarios, including independent lookup and replay-retention lifetimes.
- Explicit Codex project-skill loading check, bounded model calls and progress on stderr.
- Strict TypeScript checks, regression tests, platform CI, source-only release staging and content scans.

The model evaluation uses a small development fixture. No general success-rate advantage over a normal skill or a strong unassisted model has been established. The first release's value is the inspectable case-to-skill and revision workflow.
